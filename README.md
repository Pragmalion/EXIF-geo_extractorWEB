# Анализатор EXIF-данных

Веб-приложение на Flask для извлечения и просмотра EXIF-метаданных изображений (JPG/PNG) с отображением геометок и построением маршрута на интерактивной карте.

## Возможности

- Извлечение и отображение всех EXIF-тегов из изображений (`.jpg`, `.jpeg`, `.png`).
- Получение GPS-координат (широта/долгота) из метаданных.
- Отображение места съёмки одного фото на карте (Folium + OpenStreetMap).
- Загрузка нескольких файлов одновременно для построения маршрута между точками съёмки.
- Превью изображений в виде миниатюр прямо в карточке результата и в попапах маркеров на карте.
- Поддержка drag-and-drop при загрузке файлов.
- Тёмная адаптивная вёрстка.

## Стек технологий

- **Python 3.12**
- **Flask 3.1** — веб-фреймворк
- **Pillow** — работа с изображениями и EXIF
- **Folium** — генерация интерактивных карт
- **Werkzeug** — безопасная обработка загружаемых файлов

## Установка

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<ваш-логин>/<название-репозитория>.git
cd <название-репозитория>
```

### 2. Создать и активировать виртуальное окружение

Windows (PowerShell):
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Linux / macOS:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

## Запуск

В активированном виртуальном окружении выполните:

```bash
python app.py
```

После запуска в консоли появится сообщение вида:

```
 * Running on http://127.0.0.1:5000
```

Откройте этот адрес в браузере.

## Использование

### Анализ одного изображения

1. Нажмите на область загрузки или перетащите файл `.jpg` / `.jpeg` / `.png` в неё.
2. Нажмите кнопку **«Анализировать»**.
3. На странице отобразятся:
   - миниатюра загруженного фото;
   - таблица со всеми найденными EXIF-тегами;
   - GPS-координаты (если присутствуют в метаданных);
   - интерактивная карта с маркером места съёмки.

### Анализ нескольких изображений (маршрут)

1. При выборе файлов выделите сразу несколько (Ctrl/Shift + клик) либо перетащите группу файлов.
2. Нажмите **«Анализировать»**.
3. Для каждого файла будут показаны миниатюра и EXIF-данные.
4. Внизу страницы появится **общая карта маршрута**: все фото с геометками отметятся пронумерованными маркерами, соединёнными красной линией в порядке загрузки.
5. Если ни в одном из файлов нет GPS-координат — будет показано соответствующее сообщение.

### Ограничения

- Поддерживаемые форматы: `.jpg`, `.jpeg`, `.png`.
- Максимальный размер загрузки — **200 МБ** (значение `MAX_CONTENT_LENGTH` в `app.py`).
- Файлы сохраняются в папку `uploads/` только на время обработки и удаляются сразу после извлечения данных.

## Диагностический скрипт

Файл `EXIF_extract.py` можно запускать отдельно для проверки GPS-данных конкретного изображения из консоли. Перед запуском отредактируйте переменную `path_to_image` внутри файла:

```bash
python EXIF_extract.py
```

Скрипт выведет в консоль весь GPS-блок и сконвертированные координаты.

## Настройки

Основные параметры задаются в `app.py`:

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `UPLOAD_FOLDER` | `uploads` | Папка для временного хранения файлов |
| `ALLOWED_EXTENSIONS` | `{'png', 'jpg', 'jpeg'}` | Допустимые расширения |
| `MAX_CONTENT_LENGTH` | `200 * 1024 * 1024` | Максимальный размер загрузки (байты) |

Размер генерируемых миниатюр задаётся в `exif_utils.py` константой `THUMBNAIL_SIZE = (150, 150)`.

## Возможные проблемы

- **«В этом изображении не найдены GPS-данные»** — у фотографии нет геометки (часто отсутствует у скриншотов и изображений из мессенджеров, которые удаляют EXIF).
- **Ошибка установки `Pillow`/`numpy`** — обновите `pip`: `python -m pip install --upgrade pip`.
- **Порт 5000 занят** — измените порт в `app.py`: `app.run(debug=True, port=5001)`.
